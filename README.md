## How It Works

```
Market Data → Alibaba Brain → Task Assignment → 9 Agents → Results → Learning
                    ↑____________________ Intelligence Feedback ______________|
```

1. **Every cycle**: Alibaba reads market prices, bounty feeds, news, and agent results
2. **Decision engine**: Assigns specific tasks to each agent based on opportunity scoring
3. **Agents execute**: Each agent works autonomously in their domain
4. **Intelligence flows back**: Results are stored and used to improve future decisions
5. **Human gets one brief**: WhatsApp message once a day at 11pm UTC
